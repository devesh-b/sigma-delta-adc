When the user is away, keep working instead of blocking on questions. Choose by the north star: first-silicon success first, then better ΣΔ specs than prior TT designs, framed as learning. Log every non-obvious decision (decision, reason, alternative, reversible?) in `work/<campaign>/DECISIONS.md` and open the final report with that list. Never do anything outward-facing (push, submit) unless the user asked. Run expensive whole-system checks once, at the end.

**Why:** This is a user rule from AlphaOneSoC.
**How to apply:** See `WORKFLOW.md` §13 and [[project-sigma-delta-tt]].
