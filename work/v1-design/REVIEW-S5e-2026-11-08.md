## Answers to the five questions

**1. C1 fix: correct.**
- `model/iadc.py` (convert, after `u_hat = …`): `u_corr = (u_hat + x2/(c1·c2·W))·s` for order 2 and `(u_hat + x1/(c1·N))·s` for order 1. The residue is added in the modulator frame before demodulation, which is right.
- The chain path concatenates the per-conversion `u_corr`.
- Every S4 consumer now uses `u_corr`: `memory_uv`, `static_err_corr`, `mc_task` (INL and offset `cv`), and `cm_err_v`.
- The V1 test `model/tests/test_s4_corners.py::_pair_error` is a real check. With an ideal loop the result is exact; the old frame gives more than 1e-9 and is rejected.
- **Is 205 dB physical?** It is the correct model physics, but it is not a silicon number.
  - A constant CM→diff term e enters the sys pair as ½[f(u+e) + f(u−e)] − f(u) = e²·f''/2 for the odd part of the INL function f.
  - The even part gives 2·a·u·e, which is odd in u and cancels in the symmetric-u mean.
  - At e ≈ 4.1e-4 u (ε 8.4e-4 × 1 V), a 5 ppm cubic gives about 1e-11 V. That is the same order as the reported 3.6–5.8e-11 V. REASONED.
  - A per-point metric would show about 2·a·e·|u| ≈ 4 nV at u = 1, i.e. roughly 165–170 dB. This is a 2 ppb gain term and harmless.
  - Silicon sys-on CMRR is set elsewhere:
    - pin-path ΔR·fs·Cp,top: about 116 dB at 50 Ω (R8);
    - chopper injection mismatch;
    - the tier-1 cm2 deck gives 137–173 dB.
  - **SPEC must not quote 205 dB.** It should cite the 100 dB gate and the tier-1 evidence.

**2. Ck topology: correct.**
- In the deck (`design/tier1/gen_tier1.py` lines 202–209), the Ck top plate sits on tp2, next to Cs2. `Stp2` / `Stp2d` clear it every phi1e, so it is a sampled cap: c_samp2 = c2·(1+k). Stage 1 samples Cs1 only (shared Cs, D22).
- `cp_hold` checks out by charge conservation at vg: vo'(1 + (1+c+cp)/A) = vo(1 + (1+cp)/A) + c·vin. That gives g = 1/(1 + (1+c+cp)/A) and p = (1 + (1+cp)/A)·g. `design/tests/test_tier1.py` asserts the same algebra. PROVEN by derivation.
- **The 5 % gate and nonvac5 are a real non-vacuity check.**
  - Removing Ck takes c_samp2 from 0.75 to 0.5, so the stage-2 leak changes by 1.5×.
  - At N 256 with constant A0, the stage-2 leak dominates the INL. The commit message shows 4.40 → 5.88 ppm (+34 %), far outside 5 %.
  - The monkeypatch keys on c == c2(1+k) (`tier1_tb.py` lines 405–407); no collision with c1 is possible.
- **Scope limit:** the gated rows are legacy-OTA, N 256, 5 DC points (`tier1_tb.py` line 399). The gate validates the leak and Ck algebra, not the v2 OTA path (CL, GBW, slew) that the fast-mode results depend on. At N 4096 Ck moves INL by only 0.4 %, so the gate couldn't see it there, and doesn't need to.

**3. V5(ii) at 3 MHz: not a deck bug. OTA1 slew limit (the S5d estimate was wrong).**
- **The deck timing is fs-agnostic:**
  - `gen_tier1.py` line 33: gap 12.5 ns and tdel 5 ns are fixed.
  - Lines 108–115: the PULSE phases are h−2g (phi1, phi2), h−2g−tdel (phi1e) and a 9 ns latch at T−g+2 ns.
  - Line 116: the reset PULSE scales with T.
  - `tier1_tb.py` line 151 samples the bits at t0 + kT + 0.25T; line 156 reads the residue at tend = t0 + nT − 5 ns.
  - `knee_thresholds` (`tier1_tb.py` lines 843–848) is never called by `mode_fast2` (lines 1342–1396), so the fs < 3e6 branch cannot affect V5. PROVEN by reading the code.
- **The physics (REASONED, checked against committed deck data):**
  - The OTA1 phase width is 225 ns at 2 MHz and 141.7 ns at 3 MHz. So 12.5 V/µs at 3 MHz is roughly equivalent to 12.5 × 141.7/225 ≈ 7.9 V/µs at 2 MHz.
  - The deck at 2 MHz with OTA1 at 8 V/µs gave 143 ppm (s5d_tier1.md line 78). That matches 110–280 ppm.
  - At 4 MHz unboosted (≈ 5.3 V/µs equivalent) the deck gave 6252 ppm (s5b_tier1.md line 52). The trend is monotonic.
  - The weak dependence on GBW across the grid is the slew-limit signature.
- **Two framing errors:**
  - s5e_tier1.md line 54 compares V5(ii) to "4 MHz with the same OTAs unboosted (option (a))". Option (a) had OTA1 boosted to 25 V/µs.
  - The S5d estimate (REVIEW-S5d lines 82–84) considered only OTA1 GBW at 3 MHz. It also used t_half 150 ns (and 112.5 ns at 4 MHz) instead of the deck's h−2g = 141.7 ns (and 100 ns).
- **Confirming point** (one deck run, when the sandbox is free): 3 MHz, OTA1 SR 20, OTA2 13.5, GBW 16/20. Expect ≤ 5 ppm at N 1024.

**4. V5(i): is GBW2 15 MHz feasible, and is the current rule credible?**
- **Arithmetic:** I_tail2 = 13.5 V/µs × 0.7 pF = 9.45 µA. gm = 2π × 15 MHz × 0.7 pF = 66 µS. Per device 4.73 µA gives gm/Id ≈ 14. This is moderate inversion: with n ≈ 1.5, IC ≈ 1.5 at 27 °C.
- **At base bias it is plausible (REASONED, assumed thick-ox PMOS Ispec ≈ 60 nA per square, unverified):**
  - At 27 °C, W/L ≈ 50 and Cgs ≈ 0.1 pF, inside the deck's Cp,vg of 0.262 pF.
  - At 125 °C, the weak-inversion ceiling 1/(n·UT) falls to about 19, so reaching 14 needs IC ≈ 0.5, i.e. W/L ≈ 120. That is still OK for Cp, but tight.
- **The problem is the boost.** The deck sets `gmk = bst·2π·gbw·cl` (`gen_tier1.py` line 244), so gm scales linearly with current.
  - EKV: gm·n·UT/Id = 2/(1 + √(1+4·IC)).
  - At IC 1.5, ×1.5 current gives gm ×1.31. Boosted GBW2 ≈ 19.7 MHz, not 22.5.
  - Log-interpolating the V5(i) table at 19.7 MHz: N 1024 ≈ 5.3 ppm (**marginal FAIL** of 5), N 256 ≈ 12 ppm (pass).
  - OTA1 is at gm/Id ≈ 10 (IC ≈ 4), so its ×2 current gives gm ×1.5: boosted GBW1 ≈ 15 MHz, not 20 MHz.
- **The SPEC gate itself is a concern.** SPEC.md lines 117–118 require GBW(boost)/GBW(nom) ≥ 1.9 at every corner. That needs IC ≲ 0.07 (gm/Id ≈ 24). For OTA1 (8.75 µA per side) that means W/L in the thousands and a pF-scale Cp,vg, which would break β1 = 0.84.
- **The current rule I_tot ≈ 3.4·I_tail is credible as a planning number:**
  - The folded cascode needs I_fold ≥ 1.2·I_tail, which makes 2.4·I_tail from VDD.
  - About 1·I_tail goes to a continuous-time CMFB and bias.
  - With an SC CMFB it drops to about 2.6–2.8×.
  - It is a **lower bound when GBW-limited**: if gm/Id cannot be reached at a corner, the tail must grow beyond the SR rule. The 193 µA estimate has only 3.5 % headroom to 200 µA.

## 1. Correctness

### Critical
None.

### Major
**C-M1. The fast-mode deck scales gm linearly with boost current. Status: REASONED.**
- **Where:** `design/tier1/gen_tier1.py` line 244 (`gmk = bst * 2π * gbw_k * cl`) and line 251 (fp2 also ×bst); SPEC.md lines 115–118; s5e_tier1.md V5(i).
- **Problem:** gm ∝ I holds only in weak inversion. At the stated gm/Id of 14 (OTA2) and about 10 (OTA1), the boosted gm is ×1.31 and ×1.52, not ×1.5 and ×2.
- **Impact:** V5(i) at N 1024 becomes about 5.3 ppm against the 5 ppm target, a marginal fail. "OTA2 base GBW ≥ 15 MHz" is therefore not a sufficient spec.
- **Fix direction:**
  - Specify the **boosted loaded GBW** per OTA as an absolute row: OTA1 ≥ 20 MHz and OTA2 ≥ 22.5 MHz at every corner. Specify the base GBW separately.
  - Add a deck knob that separates the gm boost from the current boost, and rerun V5(i) with the gm ratio taken from a gm/Id lookup table.
  - Learning step for C1: sweep gm/Id against Id/(W/L) for the chosen input-pair device at tt/ss/ff and −40/27/125 °C. Then size OTA2 for base gm/Id ≈ 16–17 so the boosted value lands at 22.5 MHz.
  - Revisit the SPEC ratio-≥ 1.9 gate, which looks infeasible without a very large input pair.

**C-M2. V5(ii) at 3 MHz is OTA1 slew-limited; the s5e attribution and the S5d estimate were wrong. Status: REASONED (scaling against deck data).**
- **Where:** s5e_tier1.md lines 52–57; REVIEW-S5d-2026-11-08.md lines 80–84; `tier1_tb.py` lines 1354–1355.
- **Why:**
  - With the same deck, OTA1 at 12.5 V/µs at 3 MHz is equivalent to about 7.9 V/µs at 2 MHz, which measured 143 ppm.
  - Making 3 MHz work unboosted needs OTA1 SR of about 16 × 1.25 ≈ 20 V/µs always on. That is about +36 µA in precision mode (≈ 154 µA instead of 118 µA).
  - So the option is dominated by V5(i).
- **Fix direction:** relabel V5(ii) as "explained, option dominated" (not "suspect deck"). Optionally confirm with a single 3 MHz point at OTA1 20 V/µs.

## 2. Efficiency
- **E1.** Drop the 3 MHz no-boost option. It needs about +36 µA always on, against zero precision-mode cost for V5(i).
- **E2.** If the CMFB is switched-capacitor, the current rule drops from about 3.4× to about 2.7× I_tail, i.e. about 3.8 µA per V/µs for OTA1. Fast mode would go from 193 to about 165 µA. That leaves room for OTA2 ×2 boost (≈ 2.2 / 4.2 ppm at N 1024 / N 256) inside 200 µA, which removes the gm-ratio risk from C-M1. REASONED.
- **E3.** Sizing OTA2 for gm/Id ≈ 16–17 at base bias costs area (about 2× input-pair W) but no current. That is cheaper than raising the OTA2 tail to fix the boosted GBW.
