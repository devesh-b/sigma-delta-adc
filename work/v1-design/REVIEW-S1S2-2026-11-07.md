# REVIEW S1 (WO-02) + S2 (WO-03): sd-adc-design-reviewer, 2026-11-07

Model blob reviewed: c4269ba. Three short sandbox probes (`/tmp/rev_probe_s1*.py`, `/tmp/rev_probe_s2.py` on the sandbox). The coordinator saved this review. Verdict: **both studies are sound in substance; nothing found would make the chip non-functional.**

## Major
| # | Finding | Class | Fix |
|---|---|---|---|
| M1 | The S1 INL ranking is off at the ≤ 12 ppm level. The N = 1024 quantization floor is 6.8 ppm, and B's INL edge comes from **c1 halving, not from VREF**. At N = 4096, A0 75: A 16.3, A_half (1.2 V, c1 .125, k .5) 2.1, B 6.2, C 945, floor 0.5 ppm. At A0 80: A 9.3, A_half 1.4, B 3.7, C 541. At equal Cint1, 1.2 V gives about 3× lower INL than 2.048 V. The real trade is FSR bits against INL. Every option is far inside 100 ppm, so D3 stands | PROVEN | Re-run S1 INL at N = 4096 or with residue reconstruction, at A0 80 dB, with A_half and shared Cs |
| M2 | OTA2 offset (and OTA1 output-referred offset) are missing. Output error = 2·Vos2/(c1(N−1)): at Vos2 9 mV, N 4096, that is 17.6 µV at c1 .25 and 35 µV at c1 .125. The S2 "ota-only" rows are understated up to 8–16×. Sys and ota+sys still cancel it (constant). OTA2 needs no chopper | PROVEN (algebra) | Add e2 / x1-offset injection to iadc.py and s2_theory. SPEC: modes without system chop are characterization-only |
| M3 | The cost of OTA chop is not modelled: the chopper's effect on A0/GBW. Sys-only already meets 50 µV even at lf 5.3 (25.6 µV) | REASONED | D4 conditional: keep OTA chop only if the C1 OTA meets A0 ≥ 80 dB and settling with the chopper in place, both chopping and parked |

## Minor
| # | Finding |
|---|---|
| m1 | **Order 1 resolved.** OTA-chop-only residual = lf·Vos/N through the quantizer residue x1[N]/(c1N). Measured 18.92 ± 1.07 µV vs Vos/N 17.58 at N 512 (M = 65536). Identical to a comparator offset of c1·Vos. Sys and ota+sys cancel it; the order-1 REJECT rows were measurement resolution. Add to s2_theory. Do **not** use x1[N] residue reconstruction as the order-1 output: the chip doesn't have x1[N], so it would hide the effect. Use it only as a diagnostic. PROVEN |
| m2 | C9 rules 1–6 are correct but incomplete; add 7–12 (see SPEC §3.6) |
| m3 | White-noise scaling is a heuristic, immaterial at 100× margin. The pessimistic lf for B should be 9.3 (sys-only at 240 SPS rises to about 45 µV, still < 50) |
| m4 | The gain-drop shape A0(1 − 0.9(x/xs)²) is smooth; a real cascode drops steeply at the knee. Replace it with the C1 OTA's A(Vout) curve. Spec form: "A ≥ 80 dB for \|Vout,diff\| ≤ X V" |
| m5 | S2 ran at A0 = ∞ with option-C coefficients. Fine for µV offsets; re-run the D3 point in S3 |
| m6 | Reference recovery with shared Cs: τ_ref 10 ns/20 pF → 12.3 ppm; 100 ns/20 pF → 21.7; 100 ns/2 pF → 66.3. "Gain error only" holds only when the reference settles. The model default cd_ref of 20 pF ≈ 10,000 µm² of MIM is not in the area plan. S3: use matching (500 Ω, 5 pF pad + real decap) pairs. PROVEN |
| m7 | Averaging does not remove the deterministic quantization error at fixed DC. The N = 1024 floor is 6.8 ppm ≈ 28 µV, and noise of ~7 µV rms only partly dithers it. Budget it in S3, or use N = 4096 (0.5 ppm) |

## Efficiency
| # | Finding |
|---|---|
| E1 | B with Cs 0.5 pF (Cint1 4 pF): same area as A, saves ≈ 4000 µm² against B at 1 pF, INL unchanged. kT/C 0.54 → 0.76 µV @ 15 SPS (60× margin) |
| E2 | Chop OTA1 only. OTA2's 1/f is divided by c1(N−1)/2, and its offset cancels with sys chop. Saves one chopper (8 TGs plus clocking). PROVEN |
| E3 | c2 = 0.25 does not help INL (stage 1 dominates). Use it only to relax OTA2 swing |
| E4 | Force y[0] at reset release |
| E5 | Sys-only at 240 SPS: N 1024 gives 2.6 µV, N 4096 gives 4.7 µV (more pairs chop more 1/f). Trade against the quantization floor m7 |

## Recommendations
- **D3:** 2.048 V, c1 .125, c2 .5, k .5. Same µV noise with +0.77 b of FSR; INL 3.7–6.2 ppm at N 4096. Use Cs 0.5 pF if area is tight (E1). Alternative: 1.2 V with c1 .125 gives 1.4–2.1 ppm for the same area.
- **D4:** keep OTA chop as a config bit on OTA1 only, never as the sole offset canceller. Keep it only if the C1 OTA meets A0 ≥ 80 dB and settling with the chopper in place; otherwise drop it. The reviewer suggests sys-only as the default.
- **S3 inputs:**
  - A0 80 dB
  - INL floor (m7)
  - OTA2 offset term (M2)
  - reference (R, C) pair (m6)
  - lf 9.3 bound
  - order-1 residual lf·Vos/N
  - C9 rules 7–12

## Reviewer questions
1. What is the Vos = 9 mV basis (pair size, σ), and is the same value used for OTA2?
2. Is there an on-chip reference decap? The model default is 20 pF ≈ 10,000 µm².
3. Where does the OTA chopper sit: at the terminals or at internal folded nodes?
4. Is order 1 in v1 a characterization mode only?
5. Is overload at 1.0–1.1·VREF a hard requirement?
