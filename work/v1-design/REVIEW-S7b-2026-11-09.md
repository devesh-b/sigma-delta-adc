## Major

**S7b-M1. The OTA1 transistor limit ε_NL ≤ 6e-5 is not tied to INL.**
- Input-referred INL ≤ ε_NL·a_max/(c1·VREF) = 1.9·ε_NL. At 6e-5 that is ≈ 114 ppm, or tens of ppm after slot averaging, against a 1.333 ppm share.
- Derive from the share instead: ε_NL ≤ 1.333/(1.9·2) ≈ 3e-7. The linear ε is a gain error and serves only as a health check (≤ 1e-4).
- Consequence (REASONED): 3e-7 is met only with ≳ 14 MHz single-pole-equivalent GBW, so the step gate would become binding over the 10 MHz floor.

**S7b-M2. An isolated step from rest cannot see the in-loop slew knee.**
- WO-19 SR/2 copy: ε_NL 2.8e-8, which passes any INL-derived limit.
- Loop with the same macromodel (s5h r3): SR 9.5/10/10.5 V/µs → 4.58/1.93/0.86 ppm, knee 10.23 V/µs.
- Suspected missing mechanisms (REASONED): the Cs2 connection kick, the input switch/pad RC, the x1 state at phase start.
- Proposal: make the in-loop check (transistor OTA1 in the tier-1 deck) authoritative. Keep the step test as a diagnostic.

## Not a bug (PROVEN, code reading)
- **Identical OTA1 ε at 2 MHz base and 4 MHz boost.** step_settle.py scales gm, ip, fp2 and ts together, so the normalised waveform is identical. OTA2 differs because 22.5 MHz ≠ 2 × 10 MHz.
- **ε = 1.6e-8 is plausible** (two-pole ζ 0.945, ≈ 19 nepers), but only 1.6× above the solver tolerance (4.96e-9 V).
- **ε_NL 4.6e-10 is a numerical floor.**

## Recommended gate text (§1a)
- **(A) Step tb (diagnostic gate):**
  - steps ±{0.1…1.0} × 0.486 V from x1 = 0 and from ±0.72 V;
  - ε_dyn(a) = (vo(t_half + 10τ) − vo(t_half))/a;
  - ε_NL = max deviation of a·ε_dyn(a) from its LSQ line, divided by 0.486;
  - limits |ε_dyn| ≤ 1e-4 and ε_NL ≤ 3e-7;
  - solver: gear, reltol ≤ 1e-8, vntol ≤ 1e-10, plus a reltol/10 rerun;
  - broken copies: tail ×0.5, GBW ×0.5.
- **(B) In-loop gate, authoritative for INL:** transistor OTA1 in the tier-1 deck (OTA2 behavioural), N 1024, 2 MHz ≤ 1.333 ppm and 4 MHz boost ≤ 5 ppm, O1/O2 converged, at tt/27 and ss/−40/3.0. Broken copy: tail set for 9.5 V/µs ⇒ REJECT.
