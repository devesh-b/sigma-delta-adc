# REVIEW-C3a-2026-11-12: comparator design note + spot sims (WO-44)

Reviewer: sd-adc-design-reviewer. Read-only. Condensed by the coordinator.

## Verdict
**REVISE, then go to netlist.**

What held up:
- the circuit itself (StrongARM, buffers, NAND SR latch) and its polarity;
- differential kickback (≤ 1.86 mV, recovered);
- the metastability argument;
- the PDK mismatch finding;
- current (~0.7 µA from VDPWR).

## Findings
1. **CRITICAL (PROVEN from code): strobe phase vs C9 capture.**
   - `c9_seq.v:41` latches `comp_s` at s_tick (bit-clock fall); `:51` sets `y_dac <= comp_s` at fs_tick.
   - The C4 note fires the strobe from φIl falling, which is after s_tick. So C9 captures the previous decision: one full extra cycle of loop delay (pthomas lost ~4 dB from half a cycle).
   - The C3 note contradicts itself: it fires during φI while x2 is still integrating.
   - Options:
     - (a) fire in φS (x2 final), and capture comp_in straight into y_dac on fs_tick: drop comp_s, keep a single flop (F8), about t_half margin both ways. This changes CL-23 / D66 AMB-01.
     - (b) keep the RTL and fire mid-φI from a C9 tick, on an unsettled x2 (a few mV of settling error).
   - Broken copy: strobe on the wrong phase ⇒ REJECT.
2. **MAJOR: A_VT basis.**
   - tt_mm (~9.3 eq.) plus an injected 12 RSS to ~15.2 mV·µm, which double counts.
   - Use 12 in total: inject √(12² − 9.3²) ≈ 7.6 on top of tt_mm, or run without _mm and inject 12.
   - Set A′ (set A's input pair ×4, so the CM kick stays at 45 mV, plus set B's latch 4/0.5): ~17.7 mV 3σ (20.5 with slope1).
   - Row 105 is soft: system chop removes the constant offset.
3. **MAJOR (PROVEN): T2/T6 cannot catch a starved comparator** (33.75 ns limit vs ~1.1–1.4 ns spot; the starve copy reads 6.4 ns).
   - Keep T2 as the requirement row.
   - Add a band row: t_dec(1 mV, ss/−40/1.62) within [0.5, 3]× the spot value.
   - Use a physical broken copy (weak strobe level) plus the wrong-phase copy.
4. **Minor:**
   - The HV tail is not needed: the tail node `tl` cannot exceed VDPWR, so a 1.8 V tail gives more strobe overdrive. The HV input pair is still needed, and is an exception to D40(a) (user OK).
   - T8: cover both power-up orders, plus x2 below ground.
5. **Minor:** the 45 mV CM kick causes no state error in order 2.
   - Check OTA2 output headroom (45 mV margin) and the comparator input CM range at the fire instant.
   - Add a ±10 % R/C asymmetry variant to T5.
6. **Minor:** noise row: `.noise` is a poor proxy for a regenerative comparator. Make T4 report-only plus the hand calculation (≈ 10× margin).
7. **Minor:** T10:
   - base the timing window on C9's 48 MHz clk edge;
   - add a near-zero Δ check that q and qb are never both high at capture;
   - the 5 fF q load is optimistic: use the routed load or add a buffer.
